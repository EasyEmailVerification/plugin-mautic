# Security Policy

## Supported versions

| Version | Mautic | Supported |
|---------|--------|-----------|
| 2.0.x   | 5, 6, 7 | Yes |
| 1.0.x   | 4.4    | Yes (security and bug fixes) |
| < 1.0.2 | 4.4    | No: upgrade to 1.0.2 |

## Reporting a vulnerability

Please do **not** report security vulnerabilities in public GitHub issues.

Email **support@easyemailverification.com** with:

- a description of the issue and its impact;
- the steps to reproduce it;
- the plugin, Mautic and PHP versions.

We acknowledge reports within 3 business days and keep you informed until the issue is fixed. Please give us
reasonable time to release a fix before any public disclosure.
